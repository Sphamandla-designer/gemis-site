Setting it up

Outlook (new, Mac, web): Settings → Mail → Compose and reply → New signature → paste → Save. Outlook (classic Windows): File → Options → Mail → Signatures → New → paste into the editor. Gmail: Settings → See all settings → General → Signature → Create new → paste → Save changes. Apple Mail: Settings → Signatures → + → paste, and untick Always match my default message font. iPhone: paste into Settings → Mail → Signature (iOS keeps the text; the tile may not show). If a client asks for the code instead, open the signature on its own and copy the page source, or use the .html file.
